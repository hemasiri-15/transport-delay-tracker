## 💻 System Requirements

### Minimum Requirements

- **OS:** Linux (Ubuntu 18.04+, Debian 10+, CentOS 7+) or WSL2
- **RAM:** 512 MB
- **Disk Space:** 100 MB
- **Bash:** Version 4.0 or higher
- **Internet:** Required for API data and package installation

### Recommended

- **OS:** Ubuntu 20.04 LTS or later
- **RAM:** 1 GB
- **Disk Space:** 500 MB (for logs and historical data)
- **Bash:** Version 5.0 or higher

### Tested On

✅ Ubuntu 20.04 LTS  
✅ Ubuntu 22.04 LTS  
✅ Debian 11  
✅ WSL2 (Windows Subsystem for Linux)  
✅ CentOS 8
